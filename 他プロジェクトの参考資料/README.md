# 問題集作成キット

DP-300の学習で積み上げた「問題集の作り方・直し方」のノウハウを、他の資格・他のプロジェクトでも使えるようにまとめたもの。Claude Codeのskillとして、各プロジェクトの `.claude/skills/` にコピーして使う。

- 現在の版: **v1.1**（2026-10-08）
- 導入方法: [導入手順.md](導入手順.md)
- このキットを作った際の整理記録: [移行作業/仕分け表.md](移行作業/仕分け表.md)

## 構成

```
問題集作成キット/
├── README.md                  このファイル（目的・原本ルール・更新履歴）
├── 導入手順.md                 新しいプロジェクトに導入するときのチェックリスト
├── 移行作業/
│   └── 仕分け表.md             DP-300の資料を汎用部分とDP-300固有部分に振り分けた記録
└── skills/
    ├── quiz-authoring/         問題集の作成・改訂・レビュー・出題運用
    │   ├── SKILL.md            汎用の手順とルール（原則として書き換えない）
    │   ├── project.md          プロジェクト固有の設定（導入先ごとに書き換える）
    │   └── references/
    │       ├── guideline.md         各ルールの悪い例・改善例
    │       ├── bad-examples.md      実際に指摘を受けた失敗例
    │       └── question-formats.md  出題形式の一覧と書式
    └── term-note-authoring/    用語集・用語ノートの作成（問題集で不正解だった論点を深掘りする工程）
        ├── SKILL.md
        └── project.md
```

## 設計方針

- **汎用部分とプロジェクト固有部分を分ける**: SKILL.mdとreferences/は分野を問わない内容にし、対象試験・教材の場所・用語表記・本試験の出題形式などは、すべてproject.mdに集める。導入時に書き換えるのはproject.mdだけ
- **skillフォルダだけで完結させる**: skillフォルダの外のファイルを参照しない。フォルダをコピーするだけで動く
- **例はDP-300のものを残す**: 具体例は抽象化すると伝わらなくなるため、DP-300（Azure SQL）の実例を「例」と明記したうえで残す

## 原本ルール

- このフォルダ（DP-300ボールト内）を原本とする。各プロジェクトにあるのはコピー
- 導入先で見つかった教訓のうち、**どの問題集にも通じるもの**は原本に戻す。原本に戻したら版数を上げ、下の更新履歴に書く
- **そのプロジェクト固有の教訓**は、導入先のproject.mdか改善記録に書き、原本には戻さない
- 導入先のskillを最新にしたいときは、導入先のproject.mdを退避してから、原本のSKILL.md・references/で上書きする（project.mdは上書きしない）

## DP-300自身への適用状況

DP-300ボールトの `.claude/skills/` にあるquiz-authoring・term-note-authoringは、キット作成前の旧版のまま。ボールトルートの [[問題集作成ガイドライン]]・[[問題集の悪い実例集]]・[[翻訳用語集]] を参照している。キット版に入れ替えるかどうかは未定（[移行作業/仕分け表.md](移行作業/仕分け表.md)の「残課題」参照）。
