# 出題形式のバリエーション

SKILL.md 2-e・2-fで使う出題形式の一覧と書式。主に選択式中心のプロジェクト向け（記述式中心のプロジェクトでは「自由記述・シナリオ設計」以外は使わないことが多い）。形式は配分の目標比率で決めず、対象の知識の構造（並列比較・手順・対比・設計判断など）に合わせて選ぶ。例はDP-300（Azure SQL）のもの。採用前には必ず原文を確認する。

## 形式と学習効果の対応

| 形式 | 主な学習効果 | 向いているファイル |
|---|---|---|
| 単一選択（3択以上） | 紛らわしい選択肢との区別 | 01_用語確認 |
| 複数選択 | 観点の抜け漏れを防ぐ | 01_用語確認 |
| 並べ替え | 手順・依存関係の理解 | 01 / 02 |
| build list | 必要な要素の取捨選択＋手順の理解 | 01 / 02 |

| 分類 | 似た項目の混同防止 | 01_用語確認 |
| 複数空欄の穴埋め（空欄ごとに選択肢群） | 構文・構成の組み立て | 01 / 02 |

## 複数選択（Select all that apply）

模範解答が2つ以上の観点を含むときに使う。

- 「（複数選択、n個選ぶ）」の指示は、問題文と同じ行に続けず独立した行に書く
- 「AとBの併用」のように、他の選択肢の単語をそのまま含む選択肢を作らない（bad-examples.md 実例4）。誤答は正解と無関係な文脈から用意する

```
問題: Action Group が実行できるアクションを次からすべて選んでください。
（複数選択）

A. メール通知
B. SMS通知
C. Automation Runbook の実行
D. Azure Functions の呼び出し
E. リソースの自動スケーリング

答え: A, B, C, D
```

## 並べ替え（手順・順序）

- 正解順が選択肢の提示順（A→B→C...の単純な昇順・降順）と一致しないよう、記号の割り当てをシャッフルする。一致していると、内容を理解していなくても上から答えれば正解できてしまう
- 各ステップ間に本当に技術的な順序の必然性があるかを吟味する。必然性のない要素同士は、複数の順序を正解として認めるか、順序を問わない形式に変える

```
問題: Resource Governor を有効化する手順を正しい順に並べてください。

A. 分類子関数を作成する
B. リソースプールを作成する
C. ALTER RESOURCE GOVERNOR RECONFIGURE を実行する
D. ワークロードグループを作成する
E. 分類子関数を ALTER RESOURCE GOVERNOR WITH (CLASSIFIER_FUNCTION = ...) で登録する

答え: B → D → A → E → C
```

この例を採用する前に、各ステップの順序の必然性を原文で確認する。たとえば、A（分類子関数の作成）がB・Dより後でなければならないかどうかを確かめる。必然性がなければ、複数の順序を正解として認める。

## build list（構築リスト）

Microsoft認定試験に実在する正式な出題形式。選択肢群（正解の数より多い要素を含む）から必要な要素だけを選び、正しい順序で並べさせる。並べ替えとの違いは「不要な要素を除外する」ステップがあること。「複数ステップのうち必要なものだけを正しい順序で実行する」構造の論点に向く（環境構築手順、ユーザー作成・権限設定、テンプレートの構築など）。

- 書式: 選択肢群を記号付きで列挙し、その下に「正しい配置（上から順に）」を記号で示す（例: `C → A → D`）
- 誤答の選択肢には、なぜ不要か（別の構成向け、前提条件が異なる等）を解説に明記する
- 並べ替えと同じく、提示順のシャッフルと順序の必然性の吟味を行う
- 「記述順序」と「実行時の依存関係」が異なる論点（例: ARMテンプレートの`resources`配列の記述順と`dependsOn`の評価順）を混同しない。解説で明確に区別する

## マッチング（対応関係）

```
問題: 次のデプロイオプションと特徴を1つずつ対応させてください。

1. SQL Server on Azure VM
2. Azure SQL Managed Instance
3. Azure SQL Database

A. OSレベルまで含めて完全に制御できるIaaS
B. インスタンススコープの機能を保ちながら管理をAzureに委ねるPaaS
C. データベース単位で管理される、最も抽象化されたPaaS

答え: 1-A, 2-B, 3-C
```

対応が3組程度と少ない場合は紛れが小さいため、誤答の候補（対応先を1つ多くする等）を足すことを検討する。

## 分類（グルーピング）

```
問題: 次のストレージ種類を主な用途で分類してください。

Azure Blob Storage / Azure Disk Storage / Azure File Storage

分類先: (a) データファイル・ログファイル　(b) バックアップ　(c) フェールオーバークラスターインスタンスの共有ストレージ

答え: Disk → (a)、Blob → (b)、File → (c)
```

## 複数空欄の穴埋め（空欄ごとに選択肢群）

コマンド・構文・テンプレートの組み立てに使う。空欄は2箇所以上、各空欄に3択以上の選択肢群を用意する。書いたらSKILL.md 4節の文法検証手順を通す。原文に実在するコマンド・構文だけを使う。

## 二択＋理由（True/False with justification）

正誤判定に加えて理由を問い、勘での正解を防ぐ。本試験で二択が出ない場合は、理由の部分を選択肢化した3択以上の形にする。

## トラブルシューティング（症状→原因）

```
問題: SQL Server VMでクエリの応答が遅く、PLEが継続して低い値を示している。まず疑うべきボトルネックはどれですか。

A. CPU不足
B. メモリ不足
C. ネットワーク帯域不足
D. ディスク容量不足

答え: B
```

## 穴埋め表（比較表の空欄補充）

```
問題: 表の空欄A〜Dを埋めてください（各空欄: 可能／不可）。

| 設定方法 | SQL Server on VM | Azure SQL Database | Managed Instance |
|---|---|---|---|
| sp_configure による MAXDOP設定 | 可能 | (A) | (B) |
| ALTER DATABASE SCOPED CONFIGURATION | (C) | 可能 | 可能 |
| Resource Governor による設定 | 可能 | (D) | 可能 |

答え: A=不可、B=不可、C=可能、D=不可
```

## 自由記述・シナリオ設計

対極的な2つの業務シナリオを示し、「どちらを選ぶべきか、なぜか」を判断の観点とともに説明させる。02_応用問題向け。自由記述は答えの範囲が広がりやすいため、「判断の観点を1つ以上挙げる」のように答えの形式を問題文で指定する。
